# SharpTiming 🕑

## Description

A console app (in Python🐍) that implements timers using the Pomodoro's Method.


## Features
- Main options page from where to access and control everything.
- Fully customizable: focus time, break time, cycles to long break, colours, ... Everything is customizable.
- Records: Keep track of time spent per project and task. (currently buggy)
